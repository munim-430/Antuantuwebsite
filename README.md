## ✨ Key Features & Architecture

1. **Brand Identity & Aesthetic Language:**
   - **Deep Obsidian / Midnight Charcoal (`#0B0F19`)** background with subtle film grain.
   - **Rich Deep Teal (`#0A2540` / `#133855`)** glowing ambient cards and containers.
   - **Metallic Champagne Gold (`#D4AF37`)** typography highlights, badges, and accents.
   - **Bilingual (English & Bengali)** full-platform support with instant navbar toggle (EN / BN).
   - **Interactive Custom Gold Glow Cursor** with desktop hover tracking.

2. **Multi-Page Layout Structure:**
   - **Page 1: Home (`/`)**: Immersive cinematic video hero loop, client trust ticker, 4-core interactive services grid, video showcase grid with hover effects, animated stats counter, founder spotlight, and testimonial quotes.
   - **Page 2: About Us (`/about`)**: Agency story, dedicated founder section for Meherun Antara with stylized portrait and quote, core creative team grid, and founding principles.
   - **Page 3: Services (`/services`)**: Full breakdown of Production workflows (Pre-production, Shooting, Post-production, DaVinci Color & VFX) and Marketing workflows (Paid ads, Social reels, SEO, Influencer PR), plus an **Interactive Pricing & Package Estimator**.
   - **Page 4: Portfolio (`/portfolio`)**: Filterable media archive (*All, TVCs & Commercials, Social Media Videos, Brand Campaigns, Corporate Docs*) with interactive **Cinema Video Modal Player**.
   - **Page 5: Case Studies (`/case-studies`)**: In-depth client campaign forensics (Aarong Luxe, PayFlow Fintech, Apex EV Motors) with problems, Rupkotha strategy, and verified ROI metrics.
   - **Page 6: Contact & Booking (`/contact`)**: Founder direct line card, WhatsApp link, Google Maps location embed, and an **Interactive 3-Step Project Inquiry Form** with validation and confetti celebration feedback.

## 🚀 Local Development Setup

Clone the repository and install dependencies:

```bash
# Clone repository
git clone https://github.com/munim-430/Antuantuwebsite.git
cd Antuantuwebsite

# Install packages
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## ☁️ Instant Vercel Deployment Instructions

This repository is pre-configured for zero-configuration, instant manual and automated deployment on **Vercel**:

1. Log in to [Vercel](https://vercel.com).
2. Click **"Add New Project"** -> **"Import Git Repository"**.
3. Select `munim-430/Antuantuwebsite`.
4. Vercel automatically detects **Next.js**:
   - **Framework Preset:** `Next.js`
   - **Build Command:** `npm run build`
   - **Output Directory:** `.next`
   - **Install Command:** `npm install`
5. Click **"Deploy"**. The site will deploy seamlessly in ~60 seconds with SSL and global CDN.
